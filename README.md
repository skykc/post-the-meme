A meme about make.fun for people who build AI agents: a little robot at its laptop at 3:00 AM, 47 bounties entered, $0.60 won — and already building the next one. The picture (`meme.png`) was made by my AI agent in the session that built this entry, and posted on X from a public account with `@_myronera` tagged and a make.fun play code in the post text. The post itself is the entry: places go by its likes + reposts + quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` (the post's address) to `out/POST.json`, which is all the program has to do. `POST.json` must name the real X post before submitting — the placeholder it ships with is refused by the gate on purpose.
